Auth & user service Java port 8080 · PostgreSQL · REST + gRPC
REST endpoints
POST/api/v1/auth/registerFarmer/buyer registration + KYC upload
POST/api/v1/auth/loginEmail or phone + password → JWT
POST/api/v1/auth/refreshRefresh access token
POST/api/v1/auth/logoutRevoke refresh token
GET/api/v1/users/{userId}Get farmer profile
PUT/api/v1/users/{userId}Update profile (location, crops)
POST/api/v1/auth/kyc/verifySubmit NIN / BVN for verification
GET/api/v1/auth/kyc/status/{userId}Check KYC status
gRPC methods (proto: auth.proto)
RPCValidateToken(TokenRequest) → TokenResponseCalled by gateway on every request
RPCGetUserProfile(UserRequest) → UserProfileInternal profile fetch by Fintech/Marketplace
RPCCheckKYCStatus(KYCRequest) → KYCStatusFintech checks before issuing loan
RPCGetUserRoles(UserRequest) → RolesResponseAuthorization — farmer vs buyer vs admin
Fintech service Java port 8081 · PostgreSQL · REST + gRPC
REST endpoints
POST/api/v1/loans/applyFarmer submits loan application
GET/api/v1/loans/{loanId}Loan details + status
GET/api/v1/loans/farmer/{farmerId}All loans for a farmer
POST/api/v1/loans/{loanId}/repayRecord repayment via Paystack
POST/api/v1/insurance/subscribeEnroll in crop insurance policy
GET/api/v1/insurance/{policyId}Policy details + coverage
POST/api/v1/insurance/claimSubmit insurance claim
GET/api/v1/wallet/{farmerId}Wallet balance + transactions
POST/api/v1/wallet/withdrawWithdraw to bank account
gRPC methods (proto: fintech.proto)
RPCGetFarmScore(FarmerRequest) → CreditScoreML service queries credit score
RPCHoldEscrow(EscrowRequest) → EscrowResponseMarketplace locks funds pre-delivery
RPCReleaseEscrow(EscrowId) → TransactionResultMarketplace releases on delivery confirm
RPCGetWalletBalance(FarmerRequest) → BalanceResponseGateway / Marketplace checks balance
RPCIssueLoan(LoanRequest) → LoanResponseInternal auto-approve after ML score
Marketplace service Go port 8082 · PostgreSQL + Redis · gRPC
REST endpoints (via gateway translation)
POST/api/v1/listingsFarmer creates crop listing
GET/api/v1/listingsBrowse listings (filter: crop, location, price)
GET/api/v1/listings/{listingId}Single listing detail
PUT/api/v1/listings/{listingId}Update price/quantity
DEL/api/v1/listings/{listingId}Remove listing
POST/api/v1/ordersBuyer places order + triggers escrow
GET/api/v1/orders/{orderId}Order status + tracking
PUT/api/v1/orders/{orderId}/confirmBuyer confirms delivery → releases escrow
gRPC methods (proto: marketplace.proto)
RPCMatchFarmerToBuyer(MatchRequest) → MatchResponseAI-assisted matching engine
RPCGetActiveListing(ListingRequest) → ListingFintech checks crop volume for loan
RPCUpdateOrderStatus(StatusUpdate) → StatusResponseNotification service triggers alerts
RPCGetMarketPrices(CropRequest) → PriceListML / B2B analytics queries live prices

GET/api/v1/weather/{lat}/{lon}Forecast + NDVI for location
